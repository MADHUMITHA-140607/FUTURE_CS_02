# Phishing Email Detection & Awareness System

## 📌 Project Overview
This project was completed as part of the Future Interns Cyber Security Internship Task 2.

The objective of this project is to analyze phishing emails, identify phishing indicators, classify email risks, and create cybersecurity awareness guidelines to help users recognize and avoid phishing attacks.

---

## 🎯 Objectives
- Analyze phishing email samples
- Identify suspicious email indicators
- Classify phishing risks
- Compare phishing and legitimate emails
- Create phishing awareness guidelines

---

## 🛠️ Tools Used
- GitHub
- Google Message Header Analyzer
- MS Word
- Public phishing email repositories

## 🔍 Phishing Indicators Identified
- Suspicious sender domains
- Fake voicemail/fax notifications
- SPF/DKIM/DMARC failures
- Malicious links
- Social engineering tactics
- Suspicious attachments
- Urgency and fear-based language

---

## 🛡️ Prevention Guidelines
- Verify sender email addresses
- Avoid clicking suspicious links
- Never share passwords or OTPs
- Avoid downloading unknown attachments
- Enable multi-factor authentication
- Report suspicious emails immediately
